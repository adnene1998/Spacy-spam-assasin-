# Plan Marketing - Plateforme de Gestion de Fêtes

Ce projet contient un générateur de présentation PowerPoint pour un plan marketing complet d'une plateforme de gestion d'événements.

## 📋 Contenu de la Présentation

La présentation générée contient **15 slides** couvrant tous les aspects essentiels du plan marketing :

### 1. **SCP (Segmentation, Ciblage, Positionnement)**
- **Segmentation** : Analyse détaillée de 3 segments de marché
  - Particuliers (mariages, anniversaires, fêtes familiales)
  - Professionnels de l'événementiel
  - Petites entreprises et associations

- **Ciblage** : Identification des cibles principales et secondaires
  - Cible principale : Particuliers 25-45 ans, urbains
  - Cible secondaire : Organisateurs professionnels

- **Positionnement** : Proposition de valeur unique
  - "La plateforme tout-en-un pour des événements réussis"
  - Avantages concurrentiels et différenciation

### 2. **Les 4 P du Marketing Mix**
- **Produit (Product)** : Fonctionnalités de la plateforme
  - Gestion de budget, catalogue de prestataires, outils de planification
  - Versions gratuite et premium

- **Prix (Price)** : Stratégie tarifaire Freemium
  - Version Gratuite : Fonctionnalités de base
  - Version Premium : 29€/mois ou 290€/an
  - Version Professionnelle : 99€/mois

- **Place (Distribution)** : Canaux de distribution
  - Plateforme web et applications mobiles
  - Accessibilité 24/7, multilingue

- **Promotion** : Stratégies de communication
  - Marketing digital (SEO, SEM, réseaux sociaux)
  - Marketing d'influence et programmes de parrainage

### 3. **Buyer Personas**
Deux profils détaillés représentant les clients types :

- **Sarah (32 ans)** : L'Organisatrice Particulière
  - Cadre en marketing, organise le mariage de sa sœur
  - Recherche gain de temps et qualité

- **Marc (38 ans)** : Le Professionnel de l'Événementiel
  - Directeur d'agence, gère 20-30 événements/an
  - Besoin d'optimisation et d'outils professionnels

### 4. **Parcours d'Achat Idéal**
Analyse complète du customer journey en 4 étapes :
1. **Prise de conscience** : Découverte du problème et de la solution
2. **Considération** : Évaluation et comparaison
3. **Décision** : Inscription et upgrade
4. **Fidélisation** : Utilisation continue et recommandation

## 🚀 Utilisation

### Prérequis
```bash
pip install python-pptx
```

Ou installer toutes les dépendances :
```bash
pip install -r requirements.txt
```

### Génération de la Présentation
```bash
python create_marketing_presentation.py
```

Cela créera un fichier nommé `Plan_Marketing_Plateforme_Gestion_Fetes.pptx` dans le répertoire courant.

## 📁 Fichiers du Projet

- `create_marketing_presentation.py` : Script Python pour générer la présentation
- `Plan_Marketing_Plateforme_Gestion_Fetes.pptx` : Présentation PowerPoint générée (15 slides)
- `requirements.txt` : Liste des dépendances Python incluant python-pptx

## 🎯 Objectifs du Plan Marketing

- **Année 1** : 5000 utilisateurs actifs, 500 abonnés premium
- **Taux de conversion** : 15% visiteur → inscrit, 8% gratuit → payant
- **Taux de rétention** : 70% à 12 mois
